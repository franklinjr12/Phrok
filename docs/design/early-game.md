# Early Game (Levels 1–20)

The first twenty levels are a complete Crownfield-to-Mossvale vertical slice. Later regions, classes, and systems remain in the full game. `VITE_DEMO_MODE=true` only blocks travel beyond Crownfield and Mossvale; it does not delete data or cap character level.

## Route

Character creation → Crownfield Town → Meadows (1–5) → Old Road (5–8) → Training Sewers / Old Sewers (8–13) → Crownfield preparation → Mossvale Grove / Edge / Deep Mossvale (15–20) → Green Chapel (19–25) → Thorn Priest.

Recommended ranges are guidance. Maps are not hard-gated by level.

## Class identity

Each base class starts with its signature skill:

- Swordsman: Power Slash
- Mage: Fire Bolt
- Archer: Double Shot
- Thief: Quick Stab

Further base skills unlock at levels 1, 3, 5, 7, 9, 11, 14, and 17. Skill points still improve already learned skills.

## Hunting loop

Normal monsters remain the main XP source. Named rare drops sit on early families at roughly 0.5%–3%. Bestiary reveals name/sprite/level at 1 kill, traits at 5, common drops at 15, rare information at 30, tactics at 50, and the existing mastery bonus at 100. Receiving a hidden drop reveals it immediately. Unrevealed rares show as `Rare Drop: ???`.

Old Road Bruiser is a visible elite with a memorable reward. Silvermane Stalker is a data-driven rare variant in Deep Mossvale.

## Dungeons and bosses

Old Sewers uses density, assists, sludge/grate hazards, and a cache rather than inflated HP alone. Sewer Glutton telegraphs Devour, Sludge Splash, and rat adds. First kill opens a class reward choice.

Green Chapel uses plant/spirit enemies, bramble and silence hazards, and Thorn Priest phases (Root Snare, Spirit Bloom, Thorn Wall). First Thorn Priest kill offers cracked Sigils that reuse the ordinary item-effect and equipment systems.

## Town and campaign

Crownfield crafting, refinement, storage, healing, and hunting contracts are useful before the Sewer Glutton revenge. The Act 1/2 campaign points at maps and bosses instead of fetch loops. Hunting Board contracts remain optional farming.

## Demo milestone

After the first Thorn Priest kill around level 18–20, a completion presentation teases Blueharbor, Amber Dunes, Ironroot, Moonveil, and Starfall. The save continues. Debug coverage uses `sessionStorage.phrok-early-game-debug`.
